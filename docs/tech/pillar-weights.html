Pillar Weights & Correlations · one weighted graph, four ways

How the 12 pillars are weighted into PureScore (W_k), how markers roll up into each pillar (within-pillar weights), and how the MONIAC reservoirs feed and cross-couple the pillars. Switch the view, peel layers on/off, and filter by sex / age / life-stage to see which markers apply. Hover any item for its full name, description and context. Data-driven from pillar-weights.json + pillars.json + calc-graph.json + marker-glossary.json + range-variations.json. See the marker catalogue (Doc 02) and the sex-specific models (Doc 08).

Note on weights
Pillar weights W_k are currently sex-/age-invariant in the data (conditioned weight vectors are a tracked gap, gap:no-conditioned-weight-vectors). So the sex/age controls here change marker applicability & reference ranges, not the pillar weights. Illustrative; re-verify (README §5.6).
