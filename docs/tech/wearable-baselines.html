Baseline · Category Layer

Five categories, one defensible read.

Above the single-metric views sits a category layer. Each category fuses its metrics into one composite signal against your personal baseline band — surfacing gaps, anomalies and deviations at a glance, then drilling down to the metric.

Three levels

1
Home · all categories
7-day composite spark + today vs band + open flags. The morning scan.
2
Category summary
One unified 30-day graph — composite hero + normalized constituent ribbons, 5 switchable styles.
3
Metric detail
Baseline band with 7-day / weekly / monthly windows + robust stats.

5 summary styles (tap to compare)

A
Composite Ribbon
Composite z-line on a ±1σ band; faint metric ribbons; hatched gaps; anomaly pulses. The clinical default.
B
Deviation Matrix
One baseline-band lane per metric + today marker. Maximum legibility.
C
Stream
Stacked deviation streams — see which metric drives the category.
D
Polar Pulse
Radial spokes, today vs baseline ring; outward = better.
E
Calendar Heat
30-day grid by composite deviation + constituent sparklines.
Bands = rolling 28-day median ± MAD (robust). Anomaly = |z| ≥ 2. Sample data is synthetic, for design only.
