Clinical Validation & Sign-off · clinicians validate sex-specific calcs & critical thresholds

A clinician-facing register to validate the engine's clinical decisions: the sex-specific calculations (male vs female bands) and the critical markers & thresholds that floor a pillar to critical and fire alerts. Every value below renders live from the canonical data (calc-graph.json + range-variations.json) — you are validating exactly what the engine runs. Set each marker's status, then print or export CSV for an advisory-board review. Source: data/clinical-validation.json.

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (Conventions §5.6). This is design documentation, not a validated medical device.
24 markers · 0 validated 24 pending 0 disputed
How to use

Review each marker's bands (male vs female; critical thresholds) against current guidelines; set status validated/disputed with reviewer, role, date and comment. Print or export CSV for offline advisory-board review.
