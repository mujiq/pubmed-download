PureScore Calc Diagram

One page that holds every system that touches the number, five ways. Built for developers and architects to confirm no step is left unturned — the core pipeline, the reservoir layer, the companion meta-vector, the personalization modifiers and the safety/clinical gates. Switch view to change the lens; set the age / sex / condition filters to re-light the steps that change for that group; double-click any node to open its source page. Anchored to Doc 05 (companion vector) and the JSON-canonical engine.

How to read this
The five views share one calculation: Overview (all systems at once) · Pipeline (the exact 5-stage formula chain) · Companion (the 10 meta-dimensions that ride alongside) · Personalization (how sex/age/condition reshape ranges & weights) · Critical & Clinical (the safety cascade, confirmation gates, the 7 gated scores and the actuarial firewall). The filters annotate the diagram (they highlight which steps change for the selected group — they do not recompute; use the Calculation Explorer to run live numbers). Symbols are kept ASCII in the diagrams; the exact formulas with γ, δ, κ, φ are in the callout under the Pipeline view.
Reading order & prerequisites: numbered nodes (1→5) are the computation order — a step needs all its inbound arrows resolved before it can run (e.g. Pillar risk 3 needs marker risk 2 and the reservoir load; PureScore 4 needs every pillar). Solid arrows are required inputs; dashed arrows are modifiers/feedback. Use ⛶ Full screen (top-right) to expand any view.

The exact formulas (Pipeline view, with symbols)

Stage-by-stage
  1. Stage 1 — clinical band: raw x_i → r_i^clin ∈ [0,1] from green/yellow/red bands (cuts 0.15 / 0.50), optimum-centred within green.
  2. Stage 2 — cohort blend: r_i = max(r_i^clin, φ·r_i^cohort), φ = 0.60 — raises concern, never lowers the clinical anchor.
  3. Stage 2b — personal baseline: z_i = (x_i − μ_i^base)/σ_i^base; feedback term κ_resp·tanh(z_i/2), κ_resp = 0.10 cap. Same signal drives Trajectory + Early-warning.
  4. Stage 3 — pillar risk: ŵ_i = w_i·confidence_i; R_k = (Σ ŵ_i·r_i^γ / Σ ŵ_i)^(1/γ) + ρ_k·B̃_k, γ = 3, ρ_k ≈ 0.20 (reservoir contribution). S_k = 100·(1 − R_k).
  5. Stage 4 — critical: if a critical marker is red, R_k ← max(R_k, 0.60) (R_crit).
  6. Stage 5 — PureScore: W_k = W_k^base·m_k^cohort·m_k^goal·m_k^acute (ΣW_k=1); R_total = (Σ W_k·R_k^δ / Σ W_k)^(1/δ), δ = 2; PureScore = 100·(1 − R_total). Critical cascade: any critical pillar → PureScore ≤ 40, status CRITICAL.
Constants live in data/constants.json (canonical); change them there, never in a page.
