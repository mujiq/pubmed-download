Patient State Machine — every state a human can be in

A single, live model of all the states the five input streams can occupy for one person — Labs / biomarkers, Wearables, the Lifestyle questionnaire (PRO) and User goals — and how those four states propagate into the fifth, the AI Recommendations. Each state models a data-lifecycle phase (missing → pending → fresh → stale → conflicting) crossed with a clinical-value band (green → watch → alert → critical). Click any chip to set that stream's state and watch the recommendation engine re-derive — with the reason on every edge. Filter on the left by age, sex, life stage, pillar or persona (Appendix D).
