All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (README §5.6). This is design documentation, not a validated medical device.

How this board works
Every configuration item below is owned by a clinical lead and reviewed each quarter. A proposed change moves Draft → Under review → Approved / Changes-requested → Versioned. Approval requires panel quorum + chair sign-off, and any change is a model-version bump that must pass the release gates (Doc 14), update the evidence registry (Doc 15), and is written to the immutable audit log (Doc 16 §4.3, §5).
