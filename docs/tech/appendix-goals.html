Appendix J — User-Goals Catalogue · closes F3

A flat catalogue with an applicability vector (so a goal is offered to the right people) and a measurable target tied to a wearable / lab / PRO metric. Goal × persona is many-to-many. Each goal links the nudges that advance it (Doc 12 / Appendix H) and exposes a progress metric the wearable/lab scores, driving the UserGoals lifecycle (set → on-track → at-risk → achieved) on the state machine.

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (Conventions §5.6). This is design documentation, not a validated medical device.
lifecycle: none → set → on_track → at_risk → off_track → achieved → abandoned
