Reference-range Resolver · how a range is sliced & diced by context

A base reference range is adjusted by the patient’s sex · age · life-stage · condition · medication. This page shows the resolution order and lets you step through any marker + context to see each slice applied — with the citation behind every shift — so a developer or clinician can verify the effective range. Single source of truth: data/range-variations.json. Illustrative (README §5.6).

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (README §5.6). This is design documentation, not a validated medical device.
Resolution order · precedence: medication / condition > life-stage > sex / age
flowchart LR
  B["base range · (appendix)"] --> SX{"sex?"}
  SX --> AG{"age band?"}
  AG --> LS{"life-stage? · (sex/age-gated)"}
  LS --> CO{"condition? · (ICD-10)"}
  CO --> MD{"medication? · (ATC)"}
  MD --> EF["EFFECTIVE range · + citation"]
