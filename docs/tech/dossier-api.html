POST /v1/patients/{id}/measurements

Ingest a lab/wearable reading (trust-tier tagged); idempotent.

auth: patient|device · idempotent: yes · returns: 202 {jobId}

errors: 400 bad-unit · 401 · 409 duplicate-key · 422 implausible

classes: Measurement, Marker, TrustTier

GET /v1/patients/{id}/score

Current PureScore + overall status + binding constraint.

auth: patient|clinician · idempotent: yes · returns: 200 {value, status, cappedBy}

errors: 401 · 404

classes: PureScore, CriticalCascade, Explanation

GET /v1/patients/{id}/companion

Companion vector (Confidence, Trajectory, Early-warning, Modifiability...).

auth: patient|clinician · idempotent: yes · returns: 200 {dims}

errors: 401 · 404

classes: CompanionVector, EarlyWarning

GET /v1/patients/{id}/pillars

Per-pillar S_k, status, coverage, top contributors.

auth: patient|clinician · idempotent: yes · returns: 200 [{code,S_k,status,cov}]

errors: 401 · 404

classes: Pillar

GET /v1/patients/{id}/reservoirs

Reservoir stocks + trajectory (B_j over time).

auth: patient|clinician · idempotent: yes · returns: 200 [{id,B_j,polarity,trend}]

errors: 401 · 404

classes: Reservoir, ReservoirSystem

GET /v1/patients/{id}/questions/next

Next eligible question by applicability + prerequisites + cadence.

auth: patient · idempotent: yes · returns: 200 {ref, text, responses}

errors: 401 · 404 · 204 none-due

classes: Question, Dependency, Applicability, QuestionBank

POST /v1/patients/{id}/responses

Record an answer; applies signed pillar/reservoir weights; may trigger a validated PRO.

auth: patient · idempotent: yes · returns: 201 {scoreDelta, triggered}

errors: 400 · 401 · 409

classes: Response, Question, ValidatedPRO, Pillar, Reservoir

GET /v1/patients/{id}/nudges

Daily top-5 safe, positive-delta actions.

auth: patient · idempotent: yes · returns: 200 [{actionId,impact,ease}]

errors: 401 · 404

classes: NudgeEngine, Action

POST /v1/patients/{id}/nudges/{nid}/complete

Mark a nudge done; feeds adherence + reservoir inflow.

auth: patient · idempotent: yes · returns: 200 {streak}

errors: 401 · 404 · 409

classes: Adherence, Action, Valve

GET /v1/patients/{id}/explanation

Full explainability object for a score (contributors, weights, caveats).

auth: patient|clinician · idempotent: yes · returns: 200 {bindingConstraint, contributors, weights}

errors: 401 · 404

classes: Explanation, Pillar

POST /v1/patients/{id}/consent

Capture/withdraw consent scopes (e.g. actuarial firewall).

auth: patient · idempotent: yes · returns: 200 {scopes}

errors: 401

classes: Governance, ActuarialLayer

GET /v1/model/version

Active model version + config hash (audit).

auth: clinician|service · idempotent: yes · returns: 200 {version, hash}

errors: 401

classes: ModelVersion, ScoringConstants

POST /v1/admin/constants

Propose a constants change (gated → model-version bump + re-validation).

auth: clinician(admin) · idempotent: no · returns: 202 {proposalId}

errors: 401 · 403 · 409 gate-failed

classes: ScoringConstants, ModelVersion, ValidationHarness, Governance
