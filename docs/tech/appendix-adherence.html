Appendix H — Adherence Micro Check-ins · closes F1

One ultra-brief check-in per nudge family, fired on the nudge's cadence (EMA-friendly). The response writes back to the reservoir it was meant to drain/fill (Doc 04) and to the engagement / Trajectory companion dimensions (Doc 05), closing the loop capture → … → nudge → adherence → capture.

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (Conventions §5.6). This is design documentation, not a validated medical device.
How an adherence answer closes the loop
flowchart LR
  NUD["nudge (Doc 11/12)"] --> ASK["micro check-in (this appendix)"]
  ASK --> R["response · adherence ∈ [0,1] + reason"]
  R --> RES["reservoir inflow (Doc 04)"]
  R --> ENG["engagement / Trajectory (Doc 05)"]
  R --> FEAS["nudge feasibility (Doc 11 §3)"] --> NUD
Activation — only relevant check-ins fire
EHR-first. A coded ehr_trigger (ATC drug class · ICD-10 condition) auto-activates a check-in from the Patient360 knowledge graph, so we never re-ask what the record already states (no 'are you on metformin?'). If EHR coverage is absent, a one-time onboarding screener activates the same set. Lifestyle check-ins gate on a goals-style applicability vector (persona · age · sex · life-stage · goal). Nothing irrelevant ever fires.
Timing — captured at onboarding
Dose/event-anchored. Onboarding captures the patient's actual schedule (e.g. metformin BD-with-meals, statin nightly, levothyroxine fasting-AM, bisphosphonate weekly-AM, inhaler PRN). The micro check-in then fires in a window relative to that dose/event (post-dose EMA) with a base cadence — prompts land at the right moment, never mistimed.
Patient360 (EHR/EMR graph)
Patient360 = the EHR/EMR-derived clinical-context graph (Doc 06 §1: Condition → disease flags D / ICD-10, MedicationStatement → medication classes Mx / ATC). It both activates the right check-ins and supplies corroboration (refill PDC/MPR, lab/wearable response).
Scoring
adherence ∈ [0,1] scales the reservoir inflow; a 7-day adherence EWMA feeds nudge feasibility (Doc 11 §3) so the engine stops re-serving repeatedly-skipped actions and substitutes a lower-effort alternative. A 'stopped — side effects / fear' response carries flag=clinician and routes to safety (Doc 16).
reason taxonomy: time salience side_effect dont_believe access cost asymptomatic regimen_complexity fear other

ehr_trigger codes are illustrative (ATC drug class, ICD-10 condition) — re-map to production terminology (RxNorm / SNOMED CT) before use. UAE-priority items flagged per Doc 18 epidemiology.
