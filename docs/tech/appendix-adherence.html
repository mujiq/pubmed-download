Appendix H — Adherence Micro Check-ins · closes F1

One ultra-brief check-in per nudge family, fired on the nudge's cadence (EMA-friendly). The response writes back to the reservoir it was meant to drain/fill (Doc 04) and to the engagement / Trajectory companion dimensions (Doc 12), closing the loop capture → … → nudge → adherence → capture.

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (README §5.6). This is design documentation, not a validated medical device.
How an adherence answer closes the loop
flowchart LR
  NUD["nudge (Doc 07/16)"] --> ASK["micro check-in (this appendix)"]
  ASK --> R["response · adherence ∈ [0,1] + reason"]
  R --> RES["reservoir inflow (Doc 04)"]
  R --> ENG["engagement / Trajectory (Doc 12)"]
  R --> FEAS["nudge feasibility (Doc 07 §3)"] --> NUD
Scoring
adherence ∈ [0,1] scales the reservoir inflow; a 7-day adherence EWMA feeds nudge feasibility (Doc 07 §3) so the engine stops re-serving repeatedly-skipped actions and substitutes a lower-effort alternative.
reason taxonomy: time salience side_effect dont_believe access other
