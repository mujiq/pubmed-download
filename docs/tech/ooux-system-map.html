Provenance · which briefing workflow contributed what

Every object traces to the brief that introduced or reframed it, per the OOUX catalogue-update protocol. The canonical catalogue (pura-objects.md) is bumped, logged and source-stamped at every brief close.

Grooming rule — applies on every update of this deliverable. This dashboard is the member-facing view of the catalogue. Run each catalogue object through the OOUX object test before it becomes a graph node: the member must (1) recognise it, (2) be able to have many of them, and (3) act on it. If it fails, demote it — a descriptor that qualifies / filters / flags another object → attribute (cards + drawer only, surfaced as a pill on its parent); machinery the member never sees or acts on (engine, scoring internals, AI / selection logic, clinician-only, detection signals) → backend (status system: hidden from the graph by default, revealed by the toggle, badged BACKEND in cards); an experience / flow pattern across screens (e.g. StoryThread) → pattern (cards only). A detection signal is not an object — what the member sees is the Notification / nudge it raises. Two objects modelling the same thing collapse to one (Plan and Protocol were the same; merged into Protocol). Change the HTML only — never the catalogue: pura-objects.md and catalogue-v1.md keep these as first-class objects; this view re-tiers them for the member.

Modelling calls carried across the app: Confidence, Explanation, Provenance, Credibility, ContextualisedStatus, Adherence and Outcome are cross-cutting attributes / measures, not objects. Timeline is one canonical object; per-feature mini-timelines are views of it. Daily Summary is a shared, cross-feature surface (My Health + Nutrition & Fitness + the homescreen). PureScore is the slow outcome (a 3 to 4 month trend), never the immediate reward; the immediate reinforcement lives in Daily Summary + Insight Line + Action Funnel + Streak + sporadic FitCoins. Pillars are backend architecture (the Moniac substrate: Knobs → Reservoirs → Biomarkers → OutcomeProjections), surfacing is an experience decision.
