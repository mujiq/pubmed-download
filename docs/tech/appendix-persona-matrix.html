Appendix I — Input → Persona Determination Matrix · closes F2

The matrix that lets the engine infer a persona from the answers, not just gate questions by one. 40 personas (15 clinical + 25 lifestyle archetypes) × 38 signals.

Illustrative
All bands, weights and cut-points on this page are literature/guideline-anchored examples and must be re-verified and cohort-adjusted before any production use (README §5.6). This is design documentation, not a validated medical device.
Method
Persona posterior = softmax over per-column evidence sums. Hard priors (sex · age · life-stage · requires) zero out impossible columns BEFORE the soft evidence is summed, so e.g. a pregnancy column can never light up for a male. Many-to-many by construction: one signal supports several personas, and each persona is supported by many signals. A signal's value comes from a question answer (Appendix E), a derived flag, or a wearable/lab threshold.
Answers → persona posterior
flowchart LR
  A["answers + derived flags + wearable/lab thresholds"] --> S["matched signals"]
  P["hard priors: sex · age · life-stage · requires"] --> Z["zero impossible columns"]
  S --> SUM["Σ signed weights per persona"] --> Z --> SM["softmax → posterior"]
  SM --> FRAME["persona frame (Doc 05/12) · cohort · nudge tilt"]
Worked example
A 52-y male, South-Asian, waist above the Asian cut-point, HbA1c 6.1%, <5k steps/day → signals south_asian_ancestry (+3 south_asian_metabolic), hba1c_pre (+3 prediabetic), waist_high_asian_cut (+2), sedentary_job_low_steps (+3 desk_sedentary). Posterior peaks on south_asian_metabolic / prediabetic; pregnancy & menopause columns are zeroed by sex/age priors.
