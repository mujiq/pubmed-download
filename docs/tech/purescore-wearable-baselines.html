Baselines (Wearables)

Each wearable metric is scored against a personal baseline (empirical-Bayes μ/σ that shrinks from the cohort prior toward the patient as data accrues — Doc 05 §5.1), not a fixed cut-point. The personal z-score it produces drives Stage 2b of the score, the Trajectory arrow and the Early-warning ladder. Trust tier (D22) caps how far a signal can move a band.

How a baseline is built
μ_i = (n/(n+k))·x̄_personal + (k/(n+k))·μ_cohort; z = (x−μ)/σ. Cold-start leans on the cohort prior; sensitivity grows with n. Consumer/inferential tiers are informational-only and never set a red/critical without clinical-grade confirmation (D22).
Marker pipeline
ingest & trust-tier (Appendix B) → bands (Appendix A · Markers) → personal baseline (you are here) · mobile prototype: Wearable baselines (mobile).

Where the baseline comes from
The μ/σ above are computed by the Wearable baseline pipeline — which unifies Terra · HealthKit · Health Connect · vendor clouds, transforms every source to a canonical unit, applies the robust+adaptive formula, and runs the data-quality rules that keep a bad sample, a time-zone glitch, a dead battery or an upstream schema change from corrupting the band.
